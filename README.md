# My Dialer

Flutter-приложение для личного использования на Android.

## Возможности

- номеронабиратель на Flutter;
- запрос роли системной звонилки;
- исходящие вызовы через Android Telecom;
- собственный экран входящего и активного вызова;
- принятие, удержание и завершение вызова;
- автоматический запуск и остановка сервиса записи по состоянию вызова;
- попытка записи через Shizuku UserService с UID shell;
- fallback на обычный `AudioRecord` с явным статусом отказа.

## Ограничение сборки

APK и Gradle собираются только через GitHub Actions. Workflow запускается вручную или при изменениях в коде приложения. Локальную Android-сборку выполнять не нужно.

## Установка и первый запуск

1. Установить APK из артефакта GitHub Actions.
2. Запустить приложение и выдать разрешения для телефона, журнала вызовов, контактов и микрофона.
3. Нажать «Выбрать» и назначить My Dialer системной звонилкой.
4. Для записи через shell заранее запустить Shizuku через ADB и выдать приложению доступ Shizuku.
5. Выполнить входящий или исходящий вызов и проверить уведомление записи.

## Статус записи

Устройство Xiaomi 14T Pro с Android 16 ранее показало успешную запись обеих сторон через аудиопуть scrcpy с UID shell. Прямой `AudioRecord` в диагностическом APK и Shizuku UserService на том же устройстве вернул `STATE_UNINITIALIZED`. Новая версия сохраняет оба пути и показывает результат в foreground-уведомлении. Запись считается подтверждённой только после проверки WAV и разборчивости обеих сторон.
